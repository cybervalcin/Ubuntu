Cheat sheet

Commandes essentielles

Navigation, paquets, fichiers : les incontournables pour intervenir vite sur un poste ou un serveur.

Navigation & repérage

pwd                      # dossier courant
ls -la                   # lister avec détails
cd /etc                  # naviguer
mkdir projets && cd projets
touch notes.md           # créer un fichier
df -h                    # espace disque
du -sh .                 # taille du dossier courant

Paquets (apt)

sudo apt update
sudo apt upgrade
sudo apt install htop curl git
sudo apt remove nom_paquet
apt search docker
apt show nginx
apt list --upgradable

Fichiers & archives

cp -r source/ cible/         # copier
mv logs.tar.gz sauvegarde/   # déplacer ou renommer
rm -rf dossier               # supprimer
tar -czvf backup.tar.gz dossier/
tar -xzvf backup.tar.gz
find . -name "*.log" -delete
grep -R "motif" ./dossier

Cheat sheet

Commandes avancées

Surveillance, services, réseau et sécurité pour garder un système fiable.

Services systemd

sudo systemctl status nginx
sudo systemctl restart nginx
sudo systemctl enable nginx --now
sudo systemctl disable apache2
journalctl -xeu nginx        # logs service
systemctl list-units --type=service

Réseau

ip a                         # interfaces
ip route                     # routes
ss -tulpn                    # ports ouverts
ping -c 4 ubuntu.com
curl -I https://example.com
dig +short monsite.fr

Utilisateurs & droits

sudo adduser devops
sudo usermod -aG sudo devops
sudo chown -R devops:devops /var/www
chmod -R 750 /var/www
sudo visudo                    # éditer sudoers
getent passwd devops

À faire

Checklist rapide

Les actions immédiatement utiles lors de la prise en main d'une machine.

  • Mettre à jour le système, configurer le fuseau horaire et l'heure (NTP).
  • Créer un utilisateur non-root avec sudo et clés SSH.
  • Activer UFW avec des règles entrantes minimales (SSH, HTTP/HTTPS).
  • Installer les outils essentiels : build-essential, curl, git, unzip.
  • Sécuriser SSH : désactiver root login, utiliser des clés, changer le port si nécessaire.
  • Configurer les sauvegardes (rsync, duplicity, borg) et des alertes basiques.

Exercices courts

Pour ancrer les commandes les plus utiles.

Gestion système

Créer un utilisateur limité, lui donner accès sudo et vérifier les droits.

Redémarrer un service web, consulter ses logs sur 15 dernières minutes.

Réseau

Identifier les ports écoutant en TCP, fermer un service inutile.

Tester la résolution DNS et tracer la route vers un domaine public.

Fichiers & sauvegarde

Archiver un dossier applicatif, le restaurer ailleurs et comparer les tailles.

Mettre en place une tâche cron simple qui écrit dans un journal dédié.
