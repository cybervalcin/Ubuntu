Cheat sheet

Commandes essentielles

Navigation, paquets, fichiers : les incontournables pour intervenir vite sur un poste ou un serveur.

Navigation & repérage

Afficher le dossier courant pour savoir où vous vous situez.
pwd
Lister le contenu avec détails et fichiers cachés.
ls -la
Accéder rapidement au dossier système /etc.
cd /etc
Créer un dossier et s'y placer en une commande.
mkdir projets && cd projets
Créer un fichier vide pour prendre des notes.
touch notes.md

Espace disque & tailles

Voir l'espace disque utilisé/disponible avec des tailles lisibles.
df -h
Afficher la taille du dossier courant.
du -sh .

Paquets (apt)

Mettre à jour la liste des paquets.
sudo apt update
Installer les mises à jour disponibles.
sudo apt upgrade
Installer des outils courants (htop, curl, git).
sudo apt install htop curl git
Supprimer un paquet devenu inutile.
sudo apt remove nom_paquet
Rechercher un paquet par mot-clé.
apt search docker
Consulter les détails d'un paquet.
apt show nginx
Lister les paquets pouvant être mis à jour.
apt list --upgradable

Fichiers & archives

Copier un dossier en conservant son contenu.
cp -r source/ cible/         # copier
Déplacer ou renommer une archive.
mv logs.tar.gz sauvegarde/   # déplacer ou renommer
Supprimer un dossier avec son contenu.
rm -rf dossier               # supprimer
Créer une archive compressée du dossier.
tar -czvf backup.tar.gz dossier/
Extraire une archive compressée.
tar -xzvf backup.tar.gz
Supprimer tous les fichiers .log dans l'arborescence.
find . -name "*.log" -delete
Rechercher un motif dans tous les fichiers d'un dossier.
grep -R "motif" ./dossier

Cheat sheet

Commandes avancées

Surveillance, services, réseau et sécurité pour garder un système fiable.

Services systemd

Consulter l'état du service nginx.
sudo systemctl status nginx
Redémarrer le service nginx.
sudo systemctl restart nginx
Activer et lancer nginx au démarrage.
sudo systemctl enable nginx --now
Désactiver apache2 au démarrage.
sudo systemctl disable apache2
Afficher les derniers logs du service nginx.
journalctl -xeu nginx        # logs service
Lister les unités de service chargées.
systemctl list-units --type=service

Réseau

Afficher les interfaces réseau.
ip a                         # interfaces
Consulter la table de routage.
ip route                     # routes
Lister les ports ouverts et processus associés.
ss -tulpn                    # ports ouverts
Tester la connectivité ICMP vers ubuntu.com.
ping -c 4 ubuntu.com
Vérifier les en-têtes HTTP d'un site.
curl -I https://example.com
Tester la résolution DNS d'un domaine.
dig +short monsite.fr

Utilisateurs & droits

Créer un nouvel utilisateur.
sudo adduser devops
Ajouter l'utilisateur au groupe sudo.
sudo usermod -aG sudo devops
Changer le propriétaire d'un dossier.
sudo chown -R devops:devops /var/www
Ajuster les droits d'accès d'un répertoire.
chmod -R 750 /var/www
Éditer la configuration sudoers (sécurité).
sudo visudo                    # éditer sudoers
Vérifier l'existence d'un utilisateur.
getent passwd devops

À faire

Checklist rapide

Les actions immédiatement utiles lors de la prise en main d'une machine.

  • Mettre à jour le système, configurer le fuseau horaire et l'heure (NTP).
  • Créer un utilisateur non-root avec sudo et clés SSH.
  • Activer UFW avec des règles entrantes minimales (SSH, HTTP/HTTPS).
  • Installer les outils essentiels : build-essential, curl, git, unzip.
  • Sécuriser SSH : désactiver root login, utiliser des clés, changer le port si nécessaire.
  • Configurer les sauvegardes (rsync, duplicity, borg) et des alertes basiques.
